# Mohammad Ali Nikoei

I build practical tools for Persian and English workflows: document editing, Excel reporting, project setup and desktop customization.

ابزارهای کاربردی برای کار با اسناد فارسی و انگلیسی، گزارش‌گیری از اکسل و شخصی‌سازی دسکتاپ می‌سازم.

## Feedback / بازخورد

Found a problem or have a feature idea? Open an **Issue in the relevant project**. Persian and English reports are welcome. Include what you tried, what you expected and your operating system version so the problem can be reproduced.

برای گزارش مشکل یا پیشنهاد، در مخزن همان پروژه بخش **Issues** را باز کنید. نوشتن مراحل بروز مشکل و نسخهٔ سیستم‌عامل کمک می‌کند گزارش قابل بررسی باشد.
